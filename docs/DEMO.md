# 第四轮演示与事实清单

[正式网站](https://lsc-261013.github.io/shiye-workbench/)已在用户明确授权后发布。当前原稿已迁移到本对话内置浏览器，刷新后完整JSON一致；换浏览器的备份/导入步骤和实际发布验证见[发布记录](RELEASE-2026-10-07.md)。

先保存自己的JSON。可以在独立来源导入[标记验收示例](evidence/round-four/polygon-final.shiye.json)，不要为练习覆盖原稿而不备份。这是自制测试示例，不是客户项目。

1. 上传喜欢的图片，说明默认进入素材区；桌面打开左侧面板，拖缩略图到想放的位置，叠放在旧图上也可，旧图不被移动。拖出取消。手机点辅助添加。
2. 选图打开直接裁切。先固定16:9框拖角缩放、框内平移；再四点逐点改轮廓。解释只剪掉区域外、不透视拉正，原图和其他实例不变。确认、撤销、恢复完整图；取消不写稿。
3. Backspace删除实例并撤销，Ctrl+C/Ctrl+V复制到附近，连续粘贴与Shift多选粘贴。准备至少三步历史后，不重新点击画板，连续按Ctrl+Z三次，再按Ctrl+Shift+Z三次重做；与右上角按钮共用逻辑。解释本次编辑会话快照、共享未变原图和独立裁切。输入笔记时退格和Ctrl+Z属于文字操作，不撤销画板。
4. 添加文字，改便签正文并保存；标题、图片和自己的想法共同组成一页。多选对齐沿用第三轮。重叠是自由画板的正常状态，整理只在自己明确点击时发生。
5. 预览、导出PNG/TXT/JSON，确认实际下载位置；刷新并从另一来源恢复。四点JSON需v3新版，回退同时保存升级前v1/v2。

右上更多有快捷键说明和第三轮「创作练习」。当前固定1600×1000，12整理/150对象/100素材/30步内存历史，刷新后历史清空。没有客户效果、用户数量或效率指标。代码主要由AI辅助实现与验收，用户的需求、取舍和体验反馈不等于已独立掌握开发。

修复及发布前45项风险测试通过。第四轮原54项有效UI/产物断言、5项退役尝试有复验说明；后续连续撤销/重做、按钮一致性与输入隔离的[实操结果](evidence/continuous-undo/results.json)另行保留，不计入原统计。线上素材拖入、两种裁切、文字、连续撤销、三个格式实际下载与刷新恢复已检查。浏览器工具拦截原生Ctrl+C/V，第四轮使用标准合成事件检查，发布前两种实际按键工具入口仍未完成验收，不称OS或跨应用复制成功；实体手机、真实IME/软键盘、Mac/Safari仍需真机验证。完整说明见[交接](HANDOFF-ROUND-FOUR-2026-10-07.md)及发布记录。
