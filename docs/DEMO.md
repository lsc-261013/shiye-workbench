# 三分钟演示与事实清单

## 演示顺序

1. 首页说明用途：把零散图片、链接和借鉴点变成一页视觉方向。打开「留白之间」，指出网页样张、排版和色彩不是同等大小的卡片。
2. 在桌面把素材拖入画板，移动一次，缩放一次，撤销和重做。说明显示缩放不改变 1600 × 1000 画板坐标。
3. 替换一张横图为竖图：框的位置保持不变，图片完整容纳。打开说明，检查来源和借鉴点；原位替换不会猜测新的来源。
4. 预览、退出、导出 PNG 与文本清单。刷新后继续编辑，再导出完整备份。说明 PNG 用于展示，备份用于恢复编辑，两者不能互相替代。
5. 切换手机宽度，展示完整构图、底部素材和工具；明确手机只做轻量操作。需要跨设备时导入备份。

## 可以陈述的事实

- 已实现 Vue 3 + TypeScript 的纯前端视觉灵感工作台，有两个可编辑示例。
- 包含图片与手动链接、固定画板、桌面拖动与等比缩放、层叠、撤销重做、手机轻量编辑。
- 使用 IndexedDB 保存完整方案；PNG、文本清单和带图片的版本化 JSON 备份各有用途。
- AI 辅助实现与验收；本项目没有经过商业需求或外部用户验证。
- 实际修复过缩放最小值的浮点边界、叠放遮住手柄、笔记本画板高度适配和缩略图拖入反馈问题。
- 验证范围和证据以 `VERIFICATION.md` 为准。不得从“实现了”自动推导为“本人独立掌握”。

不能添加未经核实的客户、用户数、性能提升比例、独立开发职责、工作年限或比赛个人贡献。

## 完成后再做的四个短练习

每次只做一项，操作后用自己的话复述；不要求先学完框架课程。

1. **产品范围**：说出这款产品解决什么问题，为什么没有加入账号、无限画布和网页抓取。
2. **关键交互**：在 `BoardCanvas.vue` 找到 `dx / drag.scale`，解释为什么屏幕拖 50 像素不一定等于画板移动 50 像素；亲自移动、撤销验证。
3. **保存与备份**：导出一次备份，在另一个浏览器导入；解释“本机保存”“PNG”“完整备份”的区别。
4. **排错复述**：解释浮点数 `99.99999999999999` 为什么可能被最小尺寸 100 的校验拒绝，并运行一次测试。

这些练习尚未由用户完成，理解程度未评估。首版完成后应转向演示、学习和求职投递，不用继续加功能拖延。
