# 三分钟演示与事实清单

2026-10-06 已更新体验；工程交付与用户学习分开记录，实际结果见 `HANDOFF-2026-10-06.md` 和 `VERIFICATION.md`。

## 演示顺序

1. 首页说明用途：把零散图片、来源和笔记变成一页视觉方向。看一次示例归拢演示，再打开「留白之间」；已有草稿先备份，切换需确认。
2. 点选素材，指出左侧红框、画板选中和右侧详情的对应。拖入、移动、缩放，再撤销和重做。显示缩放不改变 1600 × 1000 坐标，一次拖动是一条历史。
3. 用自己的测试图片做原位替换，检查位置和层级保持；来源与借鉴点需自己更新。同素材有多个引用时，替换影响这些引用；移除只移除当前对象。
4. 「预览作品」查看无工具画面，返回恢复选择。「导出作品」分别生成 PNG、完整来源笔记 TXT 和可恢复 JSON；确认下载位置。刷新后继续编辑，演示备份导入需确认。
5. 手机先看全板，再横向点选参考，往下读大图与完整笔记；「素材」面板收集图片/链接。说明这是查看与轻编辑，精细排版用电脑。模拟截图不是实体手机验收。

## 可以陈述的事实

- 已实现 Vue 3 + TypeScript 的纯前端视觉灵感工作台，有两个可编辑示例。
- 包含图片与手动链接、固定画板、桌面拖动与等比缩放、层叠、撤销重做、手机轻量编辑。
- 使用 IndexedDB 保存完整方案；PNG、文本清单和带图片的版本化 JSON 备份各有用途。
- AI 辅助实现与验收；本项目没有经过商业需求或外部用户验证。

## 完成后再做的四个短练习

每次只做一项，操作后用自己的话复述；不要求先学完框架课程。

1. **产品范围**：说出这款产品解决什么问题，为什么没有加入账号、无限画布和网页抓取。
2. **关键交互**：在 `BoardCanvas.vue` 找到 `dx / drag.scale`，解释为什么屏幕拖 50 像素不一定等于画板移动 50 像素；亲自移动、撤销验证。
3. **保存与备份**：导出一次备份，在另一个浏览器导入；解释“本机保存”“PNG”“完整备份”的区别。
4. **排错复述**：解释浮点数 `99.99999999999999` 为什么可能被最小尺寸 100 的校验拒绝，并运行一次测试。
