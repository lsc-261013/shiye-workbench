## 实际发现与修正

1. **叠放遮住缩放手柄**：手柄改成画板末尾独立覆盖层，素材本身层叠不变。实际拖动后从 720×475 变为 817.762×539.496，比例保持；撤销恢复。
2. **笔记本底部画板超出首屏**：按可用宽度和高度共同计算显示缩放。在 1366×768 下画板边界为 x≈382.8、y≈136.0、宽≈846.4、高529，完整落在视口内；不改变导出坐标。
3. **侧栏拖入反馈不足**：采用指针捕获与跟随提示，越过起拖阈值后显示“松手加入画板”。实际从侧栏拖入产生第六个元素，落点 x≈694.1 / y≈669.1，没有误打开详情。
4. **手机工具位置**：把选中工具改为底部面板，保留顶部保存、撤销和导出。手机没有显示缩放手柄。
5. **最小缩放浮点边界**：最小高度计算可能得到 99.99999999999999，导致合法备份被拒；在坐标工具约束最小值，相关测试通过。

## 动效与操作证据

以直接反馈为主，只有轻量控件颜色过渡，没有滚动劫持、循环动画或入场等待。实际进行了连续拖动、稳定松手、一次撤销、预览退出、详情关闭返回原素材和手机点选。详情通过原生 dialog 保留焦点并在关闭后回到打开控件。

提供 `prefers-reduced-motion` 规则。本机验收工具应用了与该规则相同的无动画 / 无过渡覆盖样式后完成预览、返回与导出；未修改用户操作系统设置，不将此称作真实系统偏好或手机真机验证。

视觉材料调整属于 v2 允许的普通细节。未改为暗色、渐变发光风格，也未引入概念图外的编辑功能。
