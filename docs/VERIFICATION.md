## 明确的验证边界

- 手机使用浏览器视口模拟，未测试真机相册、软键盘、Safari 或所有机型。网页文件选择已验证，不能将其称为真机相册通过。
- 独立恢复验收使用同一 Chromium 引擎的两个独立源，完全隔离 IndexedDB。额外尝试外部 Edge 验收时，已连接入口的通信失败；运行、扩展与原生连接配置检查正常，但未控制成功，因此**不声称外部 Edge 或跨浏览器引擎验收通过**。没有修改浏览器设置或安装/修复扩展。
- 减少动态效果检查应用了与 CSS 规则相同的覆盖样式，未切换操作系统偏好；没有循环动画、滚动劫持或依赖动画结束的功能。
- 未实际耗尽硬盘 / 浏览器全部配额；使用可重复故障注入验证失败路径。大文件上限由自动测试验证。
- 桌面从操作系统文件管理器拖入文件的入口已实现，使用同一读图路径；本次实际拖动验证覆盖素材栏到画板，文件上传验证通过选择器，未声称完成操作系统跨窗口文件拖放实测。
- 一份草稿、30步内存历史；不做多标签页冲突合并。90MB嵌入图片上限不是内存或存储性能保证，低内存设备建议使用更小图片。无性能指标或用户规模结论。
- 系统字体可能随平台变化；相同浏览器桌面/手机模拟输出已核对一致，不扩大为不同操作系统逐像素一致。
