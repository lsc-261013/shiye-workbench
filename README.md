# 拾页 · 视觉灵感工作台

把参考图片、来源和笔记整理成一页视觉方案。Vue 3 + TypeScript + Vite，纯前端，使用 IndexedDB 保存一份本地草稿。第二轮在 2026-10-06 完成：一步看大图、就地笔记、按需素材区、空位加入和一次可撤销的整理排版，保留暖白、炭黑和朱红的拼贴审美。

这是主要由 AI 辅助实现和验收的独立练习产品。没有客户、商业用户或效果指标验证；交付不代表使用者已经独立掌握。

## 打开与启动

本地预览：[http://127.0.0.1:4186/](http://127.0.0.1:4186/)。已有草稿点「继续上次编辑」，没有草稿点「从示例开始」或「新建空白方案」。当前电脑的依赖已经安装；关机或结束服务器后，在本目录运行：

```powershell
npm run build -- --configLoader native
npm run preview -- --port 4186 --strictPort --configLoader native
```

首次拿到源码需 Node.js 22.12+（验收使用 24.15.0），先 `npm ci`。依赖安装需要网络，运行应用使用本地素材，不抓取网页。不要直接双击 `index.html`。

```powershell
npm run dev -- --port 5186 --strictPort --configLoader native
npm run check
npm test -- --configLoader native
```

测试共有 23 项，涉及备份、坐标、历史、保存、输入保护，以及第二轮整理与笔记归属。5173 留给 GroundDesk；端口占用时先检查，不强停其他项目。

不同浏览器、端口及 `localhost` / `127.0.0.1` 的草稿独立。新版继续原稿应保留原浏览器和原地址，或从旧地址导出 JSON 后导入新地址；换端口看不到旧稿不等于丢失。旧 4173 未被本轮修改。

## 使用

1. 上传图片或添加链接。新参考会尝试放入画板空位，原布局不动；没有空位的参考留在素材区，反馈会说明结果。文件也可拖入画板收集。链接由用户填写，可附截图，不自动抓网页。
2. 点选画板参考，在笔记区直接读改名称、来源和笔记，点击「保存修改」。未提交时切换、关闭选择、预览、撤销或离开首页，会选择继续编辑、放弃并继续或保存并继续。浏览器刷新/关闭有未提交提醒；未提交文字不会作为已保存草稿。
3. 「看大图」直接进入图片查看层，关闭回到原选择。素材区按需打开；已在画板的参考主操作是「定位到画板」，次级菜单的「再添加一份」保留共享图片和笔记的多实例能力。
4. 「整理排版」只在明确点击时重排当前画板，保留素材、ID、笔记和来源。采用一套按图片比例分配宽度的行布局，预留标题和 24px 间距，适合最多 **12 个画板元素**。超过时保留原布局并提示；不会自动塞满所有素材。没有空位时可选择「整理后加入」，加入和重排共同算一次历史。
5. 桌面仍可拖动、右下角等比缩放、方向键微调（Shift 为 20px）、调整前后层级。未提交笔记时先保存或取消再拖动。替换图片保留全部共享引用的外框和层叠；从画板移除只删除当前实例，素材保留。常用替换直接可见，图层和移除在笔记区「更多」。
6. 顶栏撤销/重做支持 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl/Cmd+Y。拖动和整理各算一次，历史最多 30 步；撤销后的状态会本机保存，历史列表不跨刷新。
7. 「预览作品」隐藏工具；「导出」按用途提供 PNG 作品图、TXT 完整来源笔记清单、JSON 含图片与布局的完整备份。PNG 为 1600×1000，无选中框。提示表示已生成并向浏览器发起下载，请自行确认文件保存位置。JSON 才能恢复继续编辑。

手机先看全板，再横向点选参考，往下直接读改笔记；看图、上传、链接、替换、移除、撤销、整理和导出沿用相同语义。没有自由拖动和缩放手柄。精细排版在电脑完成。

## 数据与限制

- 固定 1600×1000，数据 version 1，无存储迁移；单张 PNG/JPEG/WebP ≤12MB、≤4000万像素，最多100份素材/150个手动画板元素，嵌入图片总量≤90MB，导入文件≤100MB。12是自动整理容量，不是手动或导入的新上限。
- 最新 IndexedDB 写入完成后才显示本机保存成功。失败保留内存稿，可重试或备份；导入先校验，再确认替换。清理浏览器数据前请保存 JSON。
- 无账号、后端、云同步、AI功能、网页抓取、PDF、无限画布或专业图片编辑。同源多标签不提供冲突合并，请只用一个编辑页。
- 只有主动打开来源才访问外站；无上传、统计埋点和会话录制。开发模式有本地 Vite 热更新。
- 手机验收是浏览器视口与触屏事件模拟；实体手机、真实输入法/软键盘、Safari、跨平台字体尚未验证。保存与 PNG 失败用故障注入测试，未真实耗尽硬盘。

## 结构与验证

```text
src/components/  首页、画板、笔记、按需素材区、大图与导出弹窗
src/composables/  笔记草稿与切换保护、加入和整理操作
src/lib/          数据校验、布局、历史、本机保存、PNG 导出
src/types.ts      version 1 类型与固定画板尺寸
public/assets/    本地摄影、自制排版和配色样张
tests/            风险测试、开发故障工具与测试素材
docs/             当前状态、验收、视觉复核、交接及证据
```

`tests/harness.html` 仅开发使用：捕获真实导出 Blob、模拟文件选入/中文组合事件、保存和 PNG 故障，不进入生产构建。正常使用打开首页即可。
