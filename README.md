# 拾页 · 视觉灵感工作台

收集参考图片与来源，添加自己的文字，把想法编排成一页。Vue 3、TypeScript、Vite，纯前端，IndexedDB 保存一份本机草稿。第四轮于2026-10-07完成：两种直接裁切、左侧素材拖入、允许重叠和对象快捷键；后续Ctrl+Z连续撤销修复已完成。

这是主要由AI辅助实现与验收的独立练习产品，没有客户、商业用户或效率指标结论。

## 使用

1. 上传图片或添加链接，默认只收集到素材区。桌面点「素材区」打开左侧面板，拖缩略图到画板指定位置，或点「添加到画板」。同素材可添加多份。允许重叠，新对象通常置顶；没有空白也可添加，不改已有对象的位置、尺寸、内容或层序。拖出画板取消，边缘约束新对象。
2. 「添加文字」新增标题、小标题或便签。可改20–72字号、加粗、有限颜色和对齐；保存后全文重算高度。初始对象也允许重叠，最多1200字符，放不下保留稿并拒绝提交。
3. 点图片就地读改共享名称、来源与完整笔记。「看大图」显示原图；桌面「裁切图片」提供固定形状等比框与四点自由区域。拖角点缩放/改轮廓，拖区域内平移；固定框可选原图、1:1、4:3、16:9。四点不做透视拉伸，轮廓外透出下层或画板。确认只改当前实例，一次撤销；取消或Esc保留进入前效果。
4. Shift点选多个对象做对齐/均分；以选区边界和中心计算，数量或间距不足时拒绝。替换共享原图更新所有引用并重置它们的裁切，外框和层序保持，可撤销。
5. 画板操作状态支持Backspace/Delete移除、Ctrl+C复制快照、Ctrl+V附近粘贴、Ctrl+Z连续撤销、Ctrl+Shift+Z/Ctrl+Y重做、Esc退出、方向键微调。撤销/重做与右上角按钮共用逻辑，连续按键无需重新点击画板。多选粘贴保留相对位置，每批一次历史；连续粘贴偏移，靠右边时换另一侧，允许重叠。对象剪贴板仅本次编辑会话，不读取系统剪贴板。输入框和弹窗保留文字操作，未复制应用对象时不拦外部粘贴。右上更多有「常用快捷键」。Mac对应Cmd实现但未实测。
6. 「整理排版」是独立明确操作，最多12个元素。上传、拖入、文字、复制或粘贴都不会触发整理。整理放不下一页时保留原稿。
7. 未提交文字/笔记的切换、复制、整理、预览、导出、撤销、返回有保存/放弃保护。一次内容提交一次历史，最多30步，历史不跨刷新。
8. 「预览作品」隐藏工具；「导出」提供1600×1000 PNG、完整TXT清单和可恢复JSON。四点轮廓与笔记分别绘制，JSON保留完整原图。下载提示表示已生成并发起下载，仍需自行确认磁盘保存位置。

手机保留整板概览、素材抽屉和辅助添加、文字与笔记编辑、看图/替换/移除/历史/整理/导出。已有四点正确显示和导出；精细裁切、多选、自由拖缩在电脑完成。右上「创作练习」仍是第三轮练习示例，切换前先保存自己的JSON。

## 数据与回退

- 固定1600×1000，最多100素材、150对象、12整理元素、30步历史；PNG/JPEG/WebP单图≤12MB、≤4000万像素，嵌入图像合计≤90MB，备份≤100MB。容量粘贴整批拒绝，裁切不会减少原图资源计数。
- v1、旧v2原样可读；只有新增四点需v3，旧v1/v2不能伪装四点。未知版本、交叉/重合/越界/过小点集、损坏文件拒绝导入，不覆盖当前稿。
- 首次v1→v2同事务保留`draft/pre-version-two`；首次旧稿→v3同事务保留`draft/pre-version-three`。右上可导出升级前备份，优先pre3再pre2。每种只保留第一份快照，不是多稿历史，换稿仍应自己备份。保存失败不误报成功，原存储事务完整回滚。
- 回退先保存当前v3和升级前v1/v2，在另目录/4187运行第三轮`8a87825`，只导入v1/v2；旧程序不能读v3。具体命令见[第四轮交接](docs/HANDOFF-ROUND-FOUR-2026-10-07.md)。不要让旧代码在4186覆盖新稿。
- 无云同步、账号、后端、AI产品功能、网页抓取、跨软件图像剪贴板导入、PDF、多标签合并或完整专业图像编辑器。清理浏览器数据前保存JSON。
