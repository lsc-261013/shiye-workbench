# 拾页 · 视觉灵感工作台

把参考图片、来源笔记、独立文字和图片局部组成一张视觉方案。Vue 3 + TypeScript + Vite，纯前端，IndexedDB 保存一份本机草稿。第三轮于2026-10-07完成，新增文字、非破坏裁切、多选对齐和对象复制，延续暖白、炭黑、朱红的拼贴风格。

这是主要由AI辅助实现与验收的独立练习产品，没有客户、商业用户或效率指标验证；交付不代表使用者已经独立掌握开发。

## 使用

1. 上传图片或添加链接，新参考尝试加入空位，原布局不动。没有空位的图片保留在素材区；链接由用户填写，可附截图，不自动抓网页。
2. 「添加文字」在画板工具条。选中文字后可改为标题、小标题或便签正文，调整字号20–72、加粗、三种颜色和左/中/右对齐，点「保存修改」。文字不关联素材、来源或图片笔记。缩框保持字号，框高按全文重算；最多1200字符，放不下拒绝提交并保留稿。没有新增空位先整理或移开对象。
3. 选图片时就地读改共享名称、来源和完整笔记。「看大图」查看原图；「裁切图片」仅桌面显示。裁切可选自由、1:1、4:3、16:9或完整图，用滑块改取景，原图与结果同时预览，再确认或取消。「恢复完整图」仅影响当前实例。
4. 桌面Shift点选增减选择。多选工具显示数量与取消方法，至少2项做六种对齐，至少3项均分水平/垂直间距。以选区边界/中心计算，均分固定两端，空间不足拒绝。一次撤销恢复，不改尺寸、内容、裁切或未选对象。
5. 选中对象的「更多」集中复制对象、前后移层及移除。图片副本共享原图与笔记，位置和裁切独立；文字副本的内容和样式独立。没有空位不强行覆盖。替换共享图片会更新所有引用并重置相关裁切，原外框和层序不变，可撤销。
6. 「整理排版」仍为主动触发，最多12个元素。文字保持字号与宽度，裁切图片按显示比例布局；放不下一页保留原稿。手动/导入仍允许150个元素。桌面可拖动、缩框和方向键微调，精细编排在电脑完成。
7. 未提交文字或笔记时，切换、复制、整理、预览、导出、撤销或返回首页都有继续编辑/放弃/保存并继续保护。刷新或关闭有未提交提醒，未提交内容不会当作已保存稿。一次提交算一次历史，最多30步，历史列表不跨刷新。
8. 「预览作品」隐藏工具。「导出」提供1600×1000 PNG作品图、TXT全文与来源清单、JSON可恢复备份。提示只表示生成文件和发起下载，请自行确认保存位置。第三轮完整结构使用version2，新版可读取version1，旧版无法恢复新增文字/裁切。

手机保留整板概览、文字新增与编辑，以及看图、收集、共享笔记、替换、移除、历史、整理和导出。已有裁切正确显示/导出；精细裁切、多选对齐与拖缩在电脑完成。

右上更多菜单有「使用『创作练习』示例」，包含2份有来源摄影、3个文字对象和共享建筑图的独立裁切。切换会确认替换，先导出自己的JSON。它是练习示例，不是客户项目。

## 数据与回退

- 固定1600×1000。100份素材、150个手动/导入元素、12个自动整理元素、30步历史保持；单图PNG/JPEG/WebP≤12MB、≤4000万像素，嵌入图像总量≤90MB，备份文件≤100MB。裁切保留完整原图，不能减少资源计数。
- version1原样读取，不主动改旧稿。首次v1→v2持久化，在同一IndexedDB事务中保留`draft/pre-version-two`原始快照；右上更多可「导出升级前备份」。该来源只保留第一份升级快照，不是多稿历史，每次换稿前仍应导出JSON。失败保留旧存储与当前内存稿，可备份或重试。
- 解析失败、未知版本或对象拒绝导入，当前稿不变。文字按安全文本渲染，来源网址保留http/https校验。
- 回退前保留当前v2备份及升级前v1。建议在另一个目录、4187端口运行第二轮`6e33c18`，仅导入v1；不要让旧代码在原4186覆盖新成果。具体命令见[完整交接](docs/HANDOFF-ROUND-THREE-2026-10-07.md)。
- 无账号、后端、云同步、AI产品功能、网页抓取、PDF、多标签合并、无限画布或完整图片编辑器。同源只用一个编辑页。清理浏览器数据前保存JSON。
