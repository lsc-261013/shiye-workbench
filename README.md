# 拾页 · 视觉灵感工作台

把参考图片、链接和借鉴点编排成一页可展示、可解释、可导出的视觉方案。Vue 3 + TypeScript + Vite，纯前端，本机 IndexedDB 保存。2026-10-06 完成第一轮体验升级：首页示例编排演示、素材与画板详情联动、手机轻编辑、按用途导出及真实保存反馈。暖白、炭黑与朱红延续第一轮 A。

这是 AI 辅助完成的独立练习产品。没有客户、商业用户或效果指标的验证；代码交付不代表使用者已经独立掌握。

## 本地启动

需要 Node.js 22.12+（本次使用 24.15.0）。在本目录打开终端：

```powershell
npm ci
npm run dev -- --port 5186 --strictPort --configLoader native
```

打开终端显示的 [本地开发页面](http://127.0.0.1:5186/)。5173 留给 GroundDesk。首次依赖安装需要网络；示例摄影和排版素材随项目提供，应用不调用在线图片服务。不要直接双击 `index.html`，它需要本地服务器。

```powershell
npm test        # 16项备份、坐标、历史、存储、保存队列及输入保护测试
npm run check  # TypeScript / Vue 类型检查
npm run build  # 类型检查 + 生产构建，结果在 dist/
npm run preview -- --port 4186 --strictPort --configLoader native
```

生产预览为 [http://127.0.0.1:4186/](http://127.0.0.1:4186/)。交付时服务器保持运行；关机或终端结束后，先 `npm run build`，再运行上述 preview 命令。它只在当前电脑可访问。当前浏览器有草稿时，首页点「继续上次编辑」；没有草稿时点「从示例开始」或「新建空白方案」。

不同端口、`localhost` 与 `127.0.0.1` 的草稿互相独立。旧 4173 草稿未被本轮触碰：需要继续它，可在当前项目运行 `npm run preview -- --port 4173 --strictPort --configLoader native`，使用原来的浏览器及同一地址；也可先在旧地址导出完整 JSON，再在新地址「导入备份」。端口占用时先检查，不强行结束其他项目。

首版已于 2026-09-21 推送 [GitHub 仓库](https://github.com/lsc-261013/shiye-workbench)。本轮在本地分支 `experience/round-one-2026-10-06`，未推送、未部署。当前状态见 [STATUS](docs/STATUS.md)，本轮结果见 [完整交接](docs/HANDOFF-2026-10-06.md)。

## 使用

1. 首页「从示例开始」，或选择「留白之间」「光与日常」。首页演示明确使用示例，自动归拢一次，可重播；已有草稿优先继续。新建、示例、合法备份导入都会确认替换，可先导出备份。
2. 上传 PNG / JPEG / WebP，或手动添加链接及可选截图。点缩略图选中素材，右侧查看大图、来源与完整笔记；点 ＋ 加入画板。红色选中标记连接素材、画板对象和详情。桌面也可把缩略图拖到画板指定位置；文件可拖入画板先添加到素材栏。
3. 桌面点选后拖动位置、拖右下角等比缩放，或用方向键微调；Shift + 方向键为 20 个画板像素。辅助线支持边距和中心对齐。前移 / 后移调整叠放。
4. 「替换图片」保留所有引用的位置、外框和层叠，图片完整容纳。旧来源、标题与借鉴点不会自动改写，请检查。移除只影响该画板元素，素材栏保留。
5. 顶栏撤销 / 重做，支持 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z，Ctrl/Cmd+Y 也可重做。连续拖动只算一次；历史最多 30 步，不跨刷新保存。
6. 「预览作品」隐藏编辑工具，返回恢复选中上下文。「导出作品」按用途提供「作品图 PNG」「来源与笔记 TXT」「完整备份 JSON」；PNG 固定 1600 × 1000、无水印。完成提示表示已生成并发起浏览器下载，请自行确认文件保存位置。「更多操作」可导入完整备份或切换方案。

手机先看完整画板，再横向浏览画板里的参考，往下看选中素材的大图、来源与可展开笔记。「素材」打开底部收集面板，支持上传、链接、替换、说明、移除、撤销重做、保存和导出。横屏也沿用轻编辑，没有自由拖动、缩放手柄或复杂手势。精细编排在电脑完成。

## 数据与限制

- 无账号和跨设备同步。清除浏览器数据、隐私模式退出、浏览器回收存储都可能导致草稿丢失，请定期下载备份。
- 页面显示「已保存到本机」的前提是最新修改的 IndexedDB 写入事务完成；写入串行，旧结果不会覆盖最新状态。失败时保留内存中的编辑，可重试或导出备份。
- 单张图片 ≤ 12 MB、≤ 4000 万像素；最多 100 份素材、150 个画板元素。嵌入图片数据总量 ≤ 90 MB，导入备份 ≤ 100 MB；实际可用存储由浏览器决定。建议优先使用压缩后的网页参考图。
- 备份是含图片数据的 JSON，版本 1；不是临时图片地址。导入先校验结构、图片解码、链接协议和坐标，再要求确认替换。
- 同时在多个标签页编辑同一地址不提供冲突合并，请使用一个编辑页。方案尺寸固定，无专业图片编辑、裁剪、旋转、自由文本、云端或 AI 功能。
- 手机为浏览器窄视口模拟验收，未做真机 / Safari 全机型测试。系统字体存在平台差异；坐标和输出尺寸固定，不承诺不同系统字体渲染逐像素一致。
- 运行页面会请求本地站点文件；开发模式还有 Vite 热更新连接。用户图片、说明不主动上传，无统计埋点或会话录制。只有主动点击来源链接才打开外站。

## 项目结构

```text
src/components/  首页、拼贴、编辑器、画板、素材栏、选中详情、导出及弹窗
src/composables/ 素材拖入逻辑
src/lib/         数据校验、示例、本机存储/保存队列、历史、坐标、输入保护、PNG 导出
src/types.ts     方案与画板元素类型、固定尺寸
public/assets/  本地摄影与自制排版素材
tests/          风险相关单元测试、开发验收工具
docs/           来源、验收、视觉复核、演示和原始参考
```

`tests/harness.html` 只供本地开发验收：可模拟保存和 PNG 失败、捕获导出、检查资源请求；不会进入生产 `dist/`。它是故障注入工具，正常使用打开首页即可。
